# 意外来访

认出他好像还是一件很轻易的事情。换了发型、看到的刹那感觉陌生，但好认的是那样的气场，他还像五年前那样在那个路口刻意地打着电话，眯着眼睛，又总好像在期盼些什么。 

他来玉泉的拜访我是完全没想到的。可能恰好是来灵隐，玉泉又和西湖太近，我推荐杭州好玩的地方时词穷，便说玉泉倒是一个好去处，他居然欣然接受。他说只想 random walk 、随便走走，于是我们便经过毛像，又从教四的后面穿到他的“学院大楼”曹楼。 

我们已经三年没联系了。其实三年间我有想过给他发消息。我有时甚至梦到他，在梦境里回到我乌托邦的高中生活，我们在黑夜里偷偷地散步，我胆怯地拉着他的袖子然后警惕地避开所有可能碰到老师的去处。可是上大学之后不再有社会的压力，我们却再也没有机会一起散过一次步。我有想过如果缘分能让我们再继续在一起如今会怎么样，但这个念头一闪而过马上就被理智制止了。 

于是三年过去了。他依旧喜欢高谈阔论，喜欢精打细算手上的钱，喜欢苹果，喜欢一直盯着我的眼睛装出很无辜的样子。和老朋友聊天或许就是一种感觉——永远不愁话说，不愁话题的停止，也不愁互相的冒犯，我们互相愿意也渴盼倾听，我也好奇他如今变成了什么样子。时间的确留下了一些魔法，他的价值观变得更加圆满和自洽了，也没有之前那么咄咄逼人的锋芒了，谈吐之间没有那么张扬了；我的世界观和说话都比之前更有条理了，也比之前更加考虑别人了。但他依旧是那么绅士和体贴，我也永远会尝试用温柔接住他。写到突然想起一句话，“归来仍是少年”。 

在玉泉走了两圈，我带他去大悦城，他吵着要吃西湖醋鱼，我没依他，带他吃了新发现，最后他买了个套餐，就莫名其妙害的他请了客。不知道为什么我们聊起了一些爱情观，他似乎很惊讶我为什么能三年单身，因为工科的专业男女比一直太不均衡了。我说事实上也没有好的机会，于是他便大谈阔论起自己的爱情观，说自己讨厌相亲和征友，讨厌一见钟情更期望日久生情。他认为单方面的追求在爱情中会导致地位不平等，因此唯一理想的爱情是双向奔赴，这样的爱情难觅，因此他认为碰不到对的人就不用谈，甚至还有和父母说好一辈子不结婚云云。突然才觉得我们的想法那么近又那么远，他对一切亲密关系都保持悲观，而我永远是保持渴望和期待。于是又聊起了“害怕”。他的意思大抵可以概括为他是极端的“风险厌恶者”，所以他恐惧亲密关系等一切困难的事情，又担心生活进入到无趣的轮回，所以为了尊严和更好的生活一直在走出去的路上。突然意识到我们都在自己的路上走着，用他的话来说就是“我觉得你说的很对，但是我也对”，其实我们都在按各自的世界观运作着所谓生活的逻辑，也在尝试变得越来越好的路上。 

不知不觉就走去了小河直街又走回了地铁站，生理期走了两万步居然不觉得累。“下一站 文三路”的声音响起，我想他马上要下车了，不知道怎么样是一个相对体面的告别。

“你要走了。其实我们已经三年没见了。” 

“你觉得这三年有变化吗？肯定没有。”

“换了个发型。” 我支吾了一下，话落在嘴边又收回。 

地铁随即驶达，我目送着他走出地铁门，他简单道了别，头也不回的走了。等我打开手机check时间又抬起头的时候，看到他刚刚回了头又立马挪回去的影子。
